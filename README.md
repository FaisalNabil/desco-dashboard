# ⚡ DESCO Prepaid Portal Dashboard

An interactive and mobile-friendly dashboard for visualizing prepaid electricity consumption, recharge history, and usage insights for DESCO (Dhaka Electric Supply Company) customers.

## 🚀 Live Demo

👉 [View the Dashboard on GitHub Pages](https://faisalnabil.github.io/desco-dashboard/)

> No login required. Use any valid DESCO account/meter number to test.

---

## 📊 Features

- ✅ **Overview section** with balance, recent activity, and insights  
- 📅 **Daily and Monthly consumption** charts (BDT & kWh)
- 💳 **Recharge history** with export options
- 🔁 **Recharge vs Consumption** visual comparison
- ⚡ **Maximum demand trend** tracking
- 📱 Fully **responsive** layout with sidebar collapse on mobile
- 📄 Export data as **PDF / Excel**

---

## 🛠️ Technologies

- HTML5, CSS3, JavaScript
- Bootstrap 5 & Bootstrap Icons
- Chart.js + chartjs-plugin-datalabels
- jQuery
- GitHub Pages (for hosting)
