# DESCO Prepaid Dashboard

A modern, mobile-friendly web portal for DESCO prepaid meter users to monitor:
- Daily and Monthly Consumption
- Recharge History
- Comparison & Max Demand
- Real-time analytics (using Chart.js)

## Features
- Responsive design (Bootstrap 5)
- Interactive charts with Chart.js + animation
- Export options (PDF, Excel)
- Offline-ready with GitHub Pages
